# Student Management System

## Project Description

This is a simple Python project for managing student information and grades.

The program gets the student's name and grades, calculates the average, finds the highest and lowest grades, and checks the student's status.

## Project Structure

```text
Student_Project/
│
├── main.py
│
├── Student/
│   ├── __init__.py
│   ├── grades.py
│   └── status.py
│
└── README.md
```
## Passing Rules

- Average grade >= 10: ACC (Accepted)
- Average grade < 10: REJ (Rejected)
